## Follow-up correction — L1 cache level metadata

The eight Cortex-A53 CPU nodes each expose distinct `l1-icache` and `l1-dcache` children. The source was corrected to set `cache-level = <1>` on all 16 child nodes. No `cache-unified` property was added: instruction and data caches remain represented as split caches. The two shared L2 nodes retain `cache-level = <2>`; their `cache-unified` schema diagnostic remains unresolved pending binding inspection.

## Why no blind fix was applied

The schema output is not sufficient to infer cache topology or TSENS IP compatibility. Adding `cache-unified` to separate L1 instruction/data caches would encode a false hardware statement. Replacing the TSENS compatible with a different Qualcomm SoC's compatible could bind the wrong register/calibration/interrupt assumptions. Both would make the report greener without proving correctness.
